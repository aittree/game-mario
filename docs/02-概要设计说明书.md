## 1. 设计目标

1. **手感可调、规则可测**：物理与瓦片碰撞、玩家状态机、敌人行为、计分全部是纯逻辑，不 import pygame，`pytest` 可覆盖；手感参数集中在 `config.py`，改数值不改代码。
2. **关卡即数据**：地形、实体、出生点、主题、时限都写在 `assets/levels/*.json` 里；代码只负责解释，不硬编码任何一关。
3. **表现与模型分离**：渲染层只读「快照 + 事件」，换皮、换分辨率、换素材不动逻辑。
4. **音频可降级**：无声卡机器完整可玩。
5. **打包无损**：同一份代码 `python main.py` 与单文件 exe 行为一致，资源路径只有一处实现。
6. **规模克制**：单人开发约 2600 行（含注释与测试）；不引入 ECS、事件总线、物理引擎等重架构。

## 2. 总体架构

采用**简化四层架构**：模型层（物理/瓦片/实体）、应用层（关卡会话与界面状态机）、表现层（渲染/动画/特效/显示）、基础设施（资源/存档/音频）。依赖方向严格单向向下，基础设施可被任意层引用，但不得反向依赖业务层。


**分层依赖规则**（Code Review 阻断项）：

| 模块 | 允许依赖 | 禁止依赖 |
| --- | --- | --- |
| `config.py` | 标准库 | 其他业务模块 |
| `physics.py` | config、tilemap（只读查询） | pygame、entities、game |
| `tilemap.py` | config | pygame、entities、ui |
| `camera.py` | config | pygame、entities、ui |
| `entities/*` | config、physics、tilemap、camera（只读） | pygame、ui、audio、storage、game |
| `game.py` | entities、tilemap、camera、physics、config | pygame、ui、audio、storage |
| `storage.py` / `resource.py` | 标准库 | pygame、entities、game |
| `keymap.py` | 标准库、pygame（仅键值常量）、config，以及 `entities/base.py` 的 `InputIntent` 纯数据类型 | entities 其他模块、game、ui、audio、storage |
| `audio.py` | pygame.mixer、resource | entities、game、tilemap |
| `ui/*` | pygame、config、只读快照与事件 | 修改 tilemap / entities / game 内部状态 |
| `main.py` | 全部 | — |

> `entities/*` 需要「世界查询」（脚下是不是地、前方有没有墙），统一通过注入的 `tilemap` 与 `physics` 完成，**不得**让实体持有 `Game` 引用，避免循环依赖。

## 3. 模块划分

| 模块 | 职责 | 对外主要接口 |
| --- | --- | --- |
| `main.py` | 初始化 pygame/音频；驱动 `MENU / LEVEL_SELECT / PLAYING / PAUSED / SETTINGS / RANKING / GAME_OVER / LEVEL_CLEAR` 状态机；固定步长推进；输入采样；事件消费 | `main()` |
| `config.py` | 画布、瓦片、物理与手感参数、配色、主题表、计分表、HUD 布局 | 常量与 `gravity` 等纯函数 |
| `physics.py` | AABB 相交、瓦片扫描区间、水平/垂直解算、单向下落判定 | `overlap(a, b)`、`move_and_collide(body, dt, tilemap, flags)` |
| `tilemap.py` | 关卡 JSON 解析、图块查询（实心/单向/危险/金币）、金币与砖块移除、按帧遍历可见图块 | `TileMap.from_file()`、`solid()`、`semisolid()`、`hazard()`、`take_coin()`、`remove()` |
| `camera.py` | 死区跟随、边界钳制、图层视差偏移、世界→屏幕映射 | `Camera.update(target)`、`to_screen(x, y)`、`parallax(k)` |
| `entities/base.py` | `InputIntent` / `WorldView` 数据类、`Entity` 基类（更新/绘制状态/激活/死亡标记）、实体类型枚举 | `Entity.update()`、`Entity.aabb`、`Entity.alive` |
| `entities/player.py` | 输入意图 → 水平加速/刹车、可变跳跃、土狼时间、跳跃缓冲、踩踏、受伤、变形、火球、动画状态 | `Player.update(dt, intent, world)`、`Player.hurt()`、`Player.grow()` |
| `entities/enemies.py` | 巡逻菇、甲壳虫（含壳）、飞行蝠、水管花的感知、行为、受击 | 各自 `update()`、`on_stomp()`、`on_fireball()` |
| `entities/items.py` | 变大菇、火花、火球（含弹跳与寿命） | `update()`、`Player.try_pickup()` 消费 |
| `entities/props.py` | 移动平台（路径插值、载人）、检查点、终点旗杆 | `MovingPlatform.update()`、`Checkpoint.touch()`、`Goal.touch()` |
| `game.py` | 一关的会话：加载关卡、生成实体、固定物理子步、相机、时间、计分、连击、死亡/重生/通关、事件队列 | `LevelSession(level_path, profile)`、`step(intent, dt)`、`take_events()`、`snapshot()` |
| `storage.py` | 读写 `save.json`：最高分、累计金币、解锁进度、最佳用时、排行榜、设置；容错与原子写 | `load_profile()`、`save_profile()`、`insert_record()` |
| `resource.py` | 源码运行走工程根，exe 运行走 `sys._MEIPASS` | `resource_path(*parts)` |
| `audio.py` | 4 首主题 BGM 循环与切换、14 个音效、音量、无声卡降级 | `Audio.play()`、`Audio.play_bgm(key)`、`set_music_volume()`、`pause()` |
| `keymap.py` | 键值 → 意图（`InputIntent`）、按住/按下沿区分、暂停与界面键表 | `Keymap`、`InputIntent` |
| `ui/theme.py` | 调色板、字号、HUD 卡片矩形、按钮布局、字体获取 | `font(size)`、`hud_rects()` |
| `ui/anim.py` | 动画定义（帧数/帧时长/循环）与精灵索引映射，按状态选择帧 | `Anim.play(state, dt)`、`frame_index()` |
| `ui/renderer.py` | 每帧绘制背景视差层、地形、实体、玩家、HUD、菜单/选关/设置/排行榜/结算；按钮命中 | `draw_world()`、`draw_menu()`、`hit_*()` |
| `ui/effects.py` | 碎片、粒子、飘字、屏幕冲击、顶砖偏移 | `on_event()`、`update(dt)`、`draw()` |
| `ui/display.py` | 1280×720 画布，窗口/全屏等比缩放，鼠标坐标映射 | `Display(canvas, fullscreen)`、`to_canvas(pos)`、`present()` |

## 5. 运行时模型

- **主循环**：`while running: 事件 → 采样输入 → 固定步长推进物理 → 相机/特效 → 绘制 → present → clock.tick(60)`。
- **固定步长**：物理以 `PHYSICS_DT = 1/120 s` 为最小步长。每帧把真实 `dt` 累积进 `accumulator`，循环扣减到不足一步为止；单帧最多执行 6 步（超出则丢弃，防止卡顿后「瞬移」）。物理步长恒定保证跳跃高度、踩踏判定与拼帧率无关。
- **输入模型**：`keymap.py` 把 `KEYDOWN/KEYUP` 采样为 `InputIntent`（`left / right / jump_held / jump_pressed / sprint / fire_pressed / down`）。同一帧内所有物理子步共享同一份意图（保证「一帧内不会起跳两次」）。
- **时间基准**：重力、计时、动画、无敌闪烁全部用 `dt` 累积，不用 `pygame.time.get_ticks()` 做逻辑判断，暂停与掉帧行为一致。
- **事件模型**：模型层只产生 `GameEvent(kind, data)` 列表；`main.py` 每帧 `take_events()` 一次，翻译为音效与特效。事件不参与规则计算。
- **状态机**（界面层由 `main.py` 持有）：

```
        ┌──────────┐  开始/进度   ┌────────────┐  P/ESC  ┌──────────┐
        │   MENU   ├─────────────►│  PLAYING   ├────────►│  PAUSED  │
        └─┬──┬──┬──┘              └─┬────┬─────┘◄────────┤          │
   选关 │  │  │设置                 │    │ 旗杆         └────┬─────┘
        │  │  └────► SETTINGS        │    ▼                 │返回菜单
        │  └──────► RANKING          │  LEVEL_CLEAR          │
        │                         生命=0                     │
        └──────► LEVEL_SELECT ◄──────┴────► GAME_OVER ◄──────┘
```

- 关卡层再有一个**对局状态**（`LevelSession.state`）：`RUNNING / DEAD / CLEARED / FAILED`。`DEAD` 期间只推进死亡动画，不接受输入；`CLEARED` 期间只推进旗杆动画。

## 6. 关键数据流

### 6.1 关卡加载

```
main.py 选择关卡 "1-1"
  → storage.load_profile()                       # unlocked / settings
  → LevelSession("assets/levels/w1-1.json", profile)
      ├─ TileMap.from_file(path)                 # 18 行字符串 → grid + 校验
      ├─ spawn_entities(level["entities"])       # 按 type 创建实体并 active=False
      ├─ items 映射 "col,row" → 道具类型          # 供问号块产出
      ├─ player = Player(spawn_col, spawn_row)   # 脚底对齐该格底面
      ├─ camera.snap_to(player)                  # 立即居中，避免开局滑入
      └─ time = level["time"]，lives 继承上一关/初始 3
```

### 6.2 一帧的推进

```
pygame 事件 → keymap.sample() → InputIntent（left/right/jump_*）
   │
   ├─ accumulator += dt；while accumulator >= 1/120 且步数 < 6：
   │     session.step(intent, 1/120)                    # 固定步长
   │        ├─ player.update(...)  → 移动/跳跃/踩踏/受伤
   │        ├─ enemies/items/props.update(...)
   │        ├─ physics 解算（水平 → 垂直）
   │        ├─ 金币收集、问号块产出、砖块破碎
   │        ├─ 相机 follow、时间递减
   │        └─ 死亡/通关判定 → 切换 session.state
   ├─ effects.update(dt)；camera 平滑
   ├─ for ev in session.take_events(): audio/effects 消费
   └─ renderer.draw_world(canvas, session.snapshot(), effects)
```

### 6.3 玩家与地形的碰撞解算

```
intent → 计算 vx, vy（加速度、重力、钳制）
vx 应用 → body.x += vx*dt → 扫描水平重叠瓦片列：
     命中实心 → 贴边（右侧撞墙 x = col*TILE - w；左侧 x = (col+1)*TILE），vx=0
vy 应用 → body.y += vy*dt → 扫描垂直重叠瓦片行：
     下落命中实心/单向（仅当上一步脚底在瓦片顶面之上）→ y = row*TILE - h，vy=0，on_ground=True
     上升命中实心 → y = (row+1)*TILE，vy=0，并上报 head_bump 给 handle_bump(col,row)
```

### 6.4 顶砖与产出

```
handle_bump(col, row) → tilemap.tile_at
  ├─ 'B' 砖块：SMALL → bump 动画 + 音效；BIG/FIRE → 移除图块、碎片特效、+50
  ├─ '?' 问号块：变 'X'，按 items["col,row"] 产出：
  │       "coin" → +1 金币 +100 分；"mushroom"/"flower" → 生成实体并向上冒出 0.4 s
  └─ '#'/'M'/'X'/'P'：只播放闷响音效（无分）
```

### 6.5 存档流

```
启动 → storage.load_profile()
  ├─ 文件缺失 / JSON 损坏 / 字段类型错 → 默认 Profile（最高分 0、金币 0、unlocked 1、音量 70/80、窗口）
  └─ 兼容 version=0（只有 best_score 的旧文件）
通关 / 退出 / 设置变更 → save_profile()
  ├─ 目录不存在 → 创建 %APPDATA%\SuperTreeio
  ├─ 写 save.tmp → os.replace 原子替换
  └─ records 按分数降序保留前 10；best_times 取更小值；unlocked 只增不减
```

## 7. 关键设计决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 坐标系统 | 世界像素坐标，y 向下，原点在关卡左上 | 渲染与 pygame 一致，免去翻转变换 |
| 碰撞 | 全 AABB + 瓦片逐格扫描 | 平台游戏够用；无需 SAT/物理引擎，可完全单测 |
| 碰撞顺序 | 先水平后垂直，分别解算 | 避免贴墙时离地、踩平台边缘时被弹开等经典抖动 |
| 单向平台 | 只在下落且上一帧脚底高于瓦片顶面时生效 | 与手感的直觉一致，且实现只需一次 `prev_bottom` 比较 |
| 物理步长 | 固定 1/120 s 子步 | 高速下落（780 px/s）时每步位移 6.5 px < 瓦片 40 px，绝不穿透 |
| 输入意图 | 每帧采样一次，所有子步共用 | 防止一帧多步导致「按一次跳两次」 |
| 可变跳跃 | 松开跳跃键即削减上升速度 | 手感核心，成本仅一次速度裁剪 |
| 地形表示 | 18×N 字符网格 + 实体列表 | 关卡可用文本编辑器手工编写、可直接 diff |
| 敌人激活 | 进入相机右侧 200 px 后才活动 | 避免远处敌人提前掉坑或卡在墙里 |
| 砖块破坏 | 直接改写网格并标记 dirty | 无需重建整张地图；渲染按帧遍历可见区 |
| 相机 | 死区 + 立即吸附重生 | 视野稳定，不出现「头晕跟随」 |
| 重开 | 重载 JSON 而不是快照回滚 | 保证地形/金币/敌人状态完全复位，代码更短 |
| 渲染 | 瓦片集 + 精灵表，按索引取帧 | 换皮只换贴图；一张表内切帧，避免文件爆炸 |
| 音频 | `pygame.mixer` 预载 WAV，BGM 走 music 通道 | 无需解码库，onefile 体积可控 |
| 字体 | 随包 `msyh.ttc` | 目标机字体不确定，避免方块字 |
| 打包 | onefile 首选，onedir 备选 | 分发最简；杀软误报时切 onedir |

## 8. 异常与容错设计

| 风险 | 处理策略 |
| --- | --- |
| 关卡 JSON 损坏 / 行长度不一致 / 未知图块码 | `TileMap.from_file` 抛 `LevelError`；`main` 捕获后该关标记不可用，返回选关页并提示，不闪退 |
| 关卡缺 `spawn` 或出生点落在实心块里 | 加载时校验，出生点上移 1 格重试；仍失败则该关不可用 |
| 音频设备缺失 / mixer 初始化失败 | `Audio.init()` 捕获 `pygame.error`，`available=False`，后续播放空操作 |
| 单个音效/单首 BGM 缺失 | 只跳过该资源；BGM 缺失静音运行 |
| 图片或字体缺失 | 背景缺失用渐变纯色；瓦片缺失用纯色矩形代替；精灵缺失画色块（保留碰撞盒）；字体回退 `SysFont` |
| 存档损坏 / 无权限 | 读降级默认；写捕获异常不中断，只保留内存状态 |
| 显示器小于画布 | 窗口模式自动等比缩小（逻辑画布不变、不可拉伸）；全屏等比缩放居中 |
| 高 DPI 模糊 | `pygame.init()` 之前声明 DPI 感知（06 §6.5） |
| 打包后找不到资源 | spec 的 `datas` 收集 `assets`，路径统一 `resource_path()` |
| 长时间运行内存增长 | 瓦片/精灵按帧复用缓存 Surface；实体死亡即从列表移除；特效用完即清 |
| 掉帧 | 单帧最多 6 个物理子步，超出丢弃；动画按真实 `dt` 推进，不会「慢动作」 |
