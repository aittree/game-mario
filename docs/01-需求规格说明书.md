## 1. 引言

### 1.1 编写目的

定义「超级树里奥」的功能范围、行为细节与验收标准，作为设计、开发、测试、发布与直播讲解的共同依据。本文档面向产品、讲师、开发与测试，不面向最终玩家（玩家请看 07 用户操作手册）。

### 1.2 项目范围

交付一个基于 **Python 3 + pygame** 的 Windows 桌面横版闯关游戏：树里奥从左向右闯过 4 个关卡，踩敌人、顶砖块、吃道具、躲机关，抵达终点旗杆即通关。最终以**单个 exe 文件**分发，附带完整的瓦片地图、角色/敌人素材、背景分层图与音频。

不涉及联网、账号、对战、内购、关卡编辑器向玩家开放、Boss 战。

### 1.3 术语约定

| 术语 | 含义 |
| --- | --- |
| 瓦片 / Tile | 地形最小单位，逻辑 1 格 = 40×40 px |
| 图块码 / Tile Code | 关卡文件里表示地形类型的单字符（`#` 土块、`B` 砖块……） |
| 瓦片地图 / TileMap | 由 18 行 × N 列图块码组成的关卡地形 |
| 关卡 / Level | 一张瓦片地图 + 实体列表 + 出生点 + 主题（草原/地下/空中/城堡） |
| 实体 / Entity | 玩家、敌人、道具、平台、检查点等非地形对象，使用连续坐标（px）与 AABB 碰撞 |
| 体 / Body | 带有 `x, y, w, h, vx, vy` 的轴对齐矩形，是所有实体的碰撞基类 |
| 单向平台 / Semi-solid | 只能从上往下站立、可从下方穿过、不阻挡侧向移动的地形（图块码 `=`） |
| 顶砖 / Bump | 玩家头撞到砖块/问号块底部的行为 |
| 变体 / Power State | 玩家的三种体型状态：SMALL（小）、BIG（大）、FIRE（火力） |
| 踩踏 / Stomp | 玩家下落时脚部压在敌人头部上方造成击杀 |
| 检查点 / Checkpoint | 触碰后可改变本关重生位置的一次性标记 |
| 土狼时间 / Coyote Time | 离开地面后仍允许起跳的宽限时间（110 ms） |
| 跳跃缓冲 / Jump Buffer | 落地前提前按下跳跃键，落地瞬间自动生效（130 ms） |
| 视差 / Parallax | 背景层按相机位移的百分比滚动，营造纵深 |
| 死区 / Dead Zone | 相机跟随玩家的水平区间，玩家在其中移动时相机不动 |

## 2. 产品概述

### 2.1 产品定位

轻量、离线、开箱即用的桌面横版闯关游戏，同时是「Python 桌面游戏：从瓦片地图、物理手感、实体系统到打包」的完整教学样例。三类使用者：

- 普通玩家：双击 exe 即玩，无需安装、无需 Python。
- 教学／直播：分层清晰，可逐层讲瓦片地图、AABB 碰撞、状态机、相机、音频与打包。
- 二次开发者：关卡为纯文本 JSON、素材集中在 `assets/`，可自建关卡与换皮。

### 2.2 运行环境

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（x64） |
| 运行方式 A | conda `game` 环境（Python 3.12）+ `python main.py` |
| 运行方式 B | 直接运行 `超级树里奥.exe`，目标机无需 Python |
| 显示 | 固定 1280×720 逻辑画布；窗口模式不可手动拉伸，桌面区域不足时自动等比缩小并居中；支持全屏等比缩放 |
| 输入 | 键盘（方向键 / WASD / 空格 / Shift / X）、鼠标（菜单与按钮） |
| 音频 | 任意 Windows 音频设备；无声卡时静默降级，不影响游戏 |

### 2.3 用户使用场景

1. 双击 exe → 主菜单 →「开始游戏」→ 树里奥出生在 1-1 关卡起点。
2. ← → 加速跑、↑ 跳跃（按住跳更高）、Shift 冲刺，踩敌人、顶问号块拿蘑菇变大。
3. 吃火花进入火力状态，X 发射火球消灭远处敌人。
4. 抵达关底旗杆 → 结算 → 自动解锁下一关。
5. 关闭再打开，最高分、解锁进度、各关最佳用时与设置仍在。

## 3. 功能需求

优先级：**P0** 必须实现、**P1** 首版目标、**P2** 可选增强。

### FR-01 启动与窗口（P0）

- 启动后在屏幕居中打开 1280×720 窗口（桌面可用区域不足时自动等比缩小、保持居中、逻辑画布不变），窗口标题「超级树里奥」。
- 窗口图标为 `assets/icon.png`，exe 图标为 `assets/icon.ico`。
- exe 启动不得出现命令行黑窗；冷启动 ≤ 3 s。
- 启动后进入主菜单，不直接开局。

### FR-02 界面状态机（P0）

- 界面状态：`MENU`（主菜单）、`LEVEL_SELECT`（选关）、`PLAYING`（游戏）、`PAUSED`（暂停）、`SETTINGS`（设置）、`RANKING`（排行榜）、`GAME_OVER`（结算）、`LEVEL_CLEAR`（通关结算）。
- 合法流转：

```
MENU ──开始／选关──► PLAYING ──P/ESC──► PAUSED ──继续──► PLAYING
  │                    │  │                │ 返回菜单
  │                    │  └─死亡且生命=0──► GAME_OVER ──► MENU / 重开本关
  │                    └─触旗──────────────► LEVEL_CLEAR ──► 下一关 / 选关 / MENU
  ├─排行榜──► RANKING ──ESC/返回──► MENU
  ├─设置────► SETTINGS ──ESC/返回──► MENU
  └─退出────► 保存并退出
```

- 除 `PLAYING` 外，任何界面都不推进游戏时间（重力、敌人、计时全部暂停）。
- 暂停、结算浮层是**模态**的：其下的游戏输入一律忽略，只响应浮层按钮。

### FR-03 关卡与地形（P0）

- 初版内置 4 个关卡：`1-1 草原`、`1-2 地下`、`1-3 空中`、`1-4 城堡`；顺序解锁，通关 1-4 后回到选关并提示「全部通关」。
- 每个关卡固定 **18 行**（与 720 px 视口等高，不做纵向滚动），列数 160～200（场景宽度约 6400～8000 px）。
- 关卡数据为 `assets/levels/w1-1.json` 一类纯文本 JSON，字段见 03 §2；不得把地形硬编码进代码。
- 地形图块类型至少包含：空（`.`）、土块（`#`）、砖块（`B`）、硬块（`M`）、问号块（`?`）、已用问号块（`X`）、水管（`P`）、单向平台（`=`）、尖刺（`^`）、金币（`c`）。
- 关卡文件缺失或解析失败：跳过该关、菜单中显示为「不可用」，不得闪退。
- 关卡必须能完整通关：出生点到终点旗杆存在可行路径，无不可跳过的死路（由 05 测试的「可通关性检查」保障）。

### FR-04 移动、跳跃与手感（P0）

- ← → 或 A D 水平移动；起步有加速度（约 0.15 s 内达到最高速度），松键后有摩擦力减速，不会瞬间停住。
- 按住 Shift 为冲刺，上限速度由 320 px/s 提升到 460 px/s，加速度同时提高。
- 反向按键触发「刹车+转身」：先在原地打滑（`skid` 动画）再反向加速，滑行距离随速度增大。
- ↑ / W / 空格 起跳：基础跳跃高度约 4 格（初速 640 px/s，重力 1280 px/s²）；**按住跳跃键持续到顶点会跳得更高**，松开即削减上升速度（可变跳跃高度）。
- 跳跃宽限：离开平台边缘后 110 ms 内仍可起跳（土狼时间）。
- 跳跃缓冲：落地前 130 ms 内的按键在触地瞬间自动起跳。
- 空中可小幅调整方向（空中加速度低于地面）。
- 玩家不可穿墙、不可穿地、不可越出关卡左右边界；掉出关卡底部立即死亡。

### FR-05 地形交互（P0）

- 头部顶到砖块底部：砖块上弹 8 px 后回落（`bump`），SMALL 状态只弹不破；BIG / FIRE 状态顶碎砖块，碎片向四个方向飞散，砖块从地形中移除。
- 顶到问号块底部：播放弹跳+物品升起动画，问号块变为已用状态（`X`），按其 `items` 配置产出金币 / 变大菇 / 火花。
- 单向平台 `=`：从上方落下可站立；从下方跳跃可穿过；侧面不阻挡；玩家按住 ↓（BIG 状态）可从平台下穿。
- 水管 `P`：完全实心，可站立、可阻挡；不可进入（不做管道传送）。
- 尖刺 `^`：非实心但接触即受伤（BIG/FIRE 掉一级，SMALL 死亡）。
- 土块 `#`、硬块 `M`、已用问号块 `X`：完全实心、不可破坏。

### FR-06 敌人与踩踏（P0）

- 四类敌人：

| 敌人 | 行为 | 击杀方式 | 接触伤害 |
| --- | --- | --- | --- |
| 巡逻菇 | 左右巡逻 80 px/s，撞墙或到平台边缘掉头 | 踩踏 / 火球 | 是 |
| 甲壳虫 | 巡逻 110 px/s，撞墙掉头 | 踩踏缩壳 → 踢壳滑行（420 px/s）撞死其他敌人，撞墙 3 次后消失 / 火球 | 是（滑行壳同样是危险物） |
| 飞行蝠 | 围绕锚点正弦飞行（振幅 60 px、周期 2.4 s） | 仅火球 | 是 |
| 水管花 | 每 2.6 s 在管内升降一轮（露出 1.4 s） | 仅火球 | 是（露出时） |

- 踩踏判定：玩家 `vy > 0`（下落）且脚部进入敌人头部上方 12 px 带内，且水平重叠 ≥ 6 px → 击杀，玩家 `vy` 重置为 -420（弹起）。
- 火球击杀：火球 AABB 与敌人重叠 → 敌人消散（`poof` 特效），火球消失。
- 连续踩踏计分链：100 → 200 → 400 → 800 → 1000（之后固定 1000），玩家着地或受伤后清零。
- 敌人只在「进入相机右侧 200 px 之内」后开始活动（`active` 标记），此前静止，避免远处敌人提前掉坑。
- 敌人不得与玩家在关卡加载首帧重叠：关卡文件必须保证出生点周围 3 格内无敌人。

### FR-07 能力状态与道具（P1）

- 玩家三种状态：

| 状态 | 碰撞盒 | 受伤结果 | 特殊能力 |
| --- | --- | --- | --- |
| SMALL | 26×36 | 直接死亡 | 无 |
| BIG | 26×56 | 降为 SMALL（触发 1.2 s 无敌闪烁） | 顶碎砖块、蹲下穿单向平台 |
| FIRE | 26×56 | 降为 BIG（触发 1.2 s 无敌闪烁） | 同上 + 发射火球 |

- 变大菇：顶问号块产出，水平移动 90 px/s，碰墙掉头，落地后持续行走；吃到 → SMALL 升 BIG，BIG/FIRE 则 +100 分。变大时角色视觉从脚底向上长高，碰撞盒同步切换，头顶若被地形压住则先下压位置再判断。
- 火花：顶问号块产出（由关卡 `items` 配置决定，见 03 §2.1），静止 8 s 后消失；吃到 → 升 FIRE；FIRE 状态吃到 +100 分。
- 火球：FIRE 状态按 X 发射，速度 520 px/s，最多同时 2 颗，冷却 180 ms；落地弹跳 2 次后消失（撞墙只反向，不计数）；击杀敌人 +200 分。
- 受伤无敌：受伤后 1.2 s 无敌，期间角色每 60 ms 闪烁一次，不与敌人/尖刺结算，但**仍会掉坑死亡**。
- 变形瞬间 0.3 s 内暂停伤害结算，避免同一帧连续掉级。

### FR-08 金币与计分（P0）

- 金币 `c`：玩家 AABB 与金币格重叠即收集（+1 金币、+100 分），播放金币音效与飘字。
- 每累计 100 枚金币 +1 生命（金币计数跨关累计，存档保存累计金币数）。
- 计分表：

| 行为 | 分数 |
| --- | --- |
| 收集金币 | +100 |
| 踩踏敌人（连击 1/2/3/4/5+） | 100 / 200 / 400 / 800 / 1000 |
| 火球击杀敌人 | +200 |
| 顶碎砖块 | +50 |
| 顶问号块（无论产出） | +50 |
| 通关剩余时间 | +10 × 剩余时间单位 |
| 通关固定奖励 | +1000 |

- 分数只增不减；0 分不进入排行榜。
- 顶部 HUD 实时显示分数、金币、世界（关卡名）、时间、生命。

### FR-09 生命、死亡与检查点（P0）

- 初始生命 3；死亡扣 1 条。
- 死亡流程：角色向上弹起 → 无碰撞下落出画面（1.2 s）→ 生命 -1 → 若生命 > 0，从最近检查点（无则关卡出生点）重生，时间与地形**全部恢复初始状态**（敌人、金币、砖块、问号块复位）；若生命 = 0 → 进入 `GAME_OVER` 结算。
- 检查点：触碰后记录重生点（含墙旗视觉升起），一关内只生效一次，播放检查点音效，分数不变。
- 重生后 1.5 s 内角色无敌（不闪烁则改为闪烁），相机立即吸附到重生点。

### FR-10 时间限制（P1）

- 每关从 300 时间单位开始，每 0.4 s 减 1（合计 120 s 真实时间）。
- 时间 ≤ 100 时 HUD 时间数字变红并以 0.5 s 周期脉动。
- 时间归零：立即死亡（等同掉坑，不播放受伤音）。
- 通关时剩余时间按 FR-08 折算分数；暂停期间计时停止。

### FR-11 终点与通关（P0）

- 终点为旗杆实体（`goal`），包含杆体与旗帜；玩家 AABB 与杆体水平范围重叠即触发通关。
- 通关动画：角色吸附到杆上并沿杆下滑 0.6 s → 旗子降下 → 1.0 s 后进入 `LEVEL_CLEAR` 结算浮层。
- 结算浮层显示：本关分数、金币、剩余时间、本关用时；提供「下一关」「重玩本关」「返回菜单」。
- 通关记录：写入存档（解锁下一关、更新本关最佳用时、更新最高分、累计金币）。
- 最后一关通关：浮层显示「全部通关」，只提供「重玩」「返回菜单」。

### FR-12 相机与背景（P0）

- 相机只做水平滚动，垂直固定 `y = 0`（关卡高度等于视口高度）。
- 死区跟随：玩家屏幕横坐标在 38%～55% 之间时相机不动；超出后相机以玩家速度跟随，并留有小幅缓动（不抖动）。
- 相机范围钳制在 `[0, 关卡宽度 - 1280]`；重生、关卡开始时相机立即居中到玩家。
- 背景三层视差：天空层静止、远景层 0.35×、近景层 0.7× 相机位移；每套主题（草原/地下/空中/城堡）各一套图。
- 地下主题额外叠加一层低亮度遮罩（α≈0.35）与玩家周围 220 px 半径的提亮渐变（P1）。

### FR-13 HUD（P0）

- HUD 为画布顶部 72 px 高的半透明横条，包含：分数（左）、金币（含金币图标与 × 计数）、世界（`1-1`）、时间（秒表图标 + 三位数）、生命（`× N`）。
- HUD 不随相机滚动，不参与任何碰撞。
- 数值变化时只更新数字，不做整条重绘。

### FR-14 主菜单、选关、设置与排行榜（P1）

- 主菜单：背景（`bg_menu.png` + 视差云）、Logo、标题「超级树里奥」、版本号、最高分，四个按钮：开始游戏、选择关卡、排行榜、设置；右下角「退出」。
- 「开始游戏」= 从存档进度中最高解锁关卡开始；无进度则从 1-1 开始。
- 选关页：4 张关卡卡片（缩略色块 + 主题名 + 最佳用时 + 锁图标），未解锁关卡置灰且不可点击；ESC 返回。
- 设置页：音乐音量、音效音量（0～100，步进 10）、显示模式（窗口/全屏）、显示帧率（开/关，仅调试用）。
- 排行榜：本机前 10 名，按分数降序；显示名次、分数、金币、到达关卡、登记日期；0 分不入榜。
- 所有界面支持鼠标悬停高亮与点击，菜单音效统一 `sfx_menu`。

### FR-15 暂停与重开（P0）

- 游戏中按 P 或 ESC 暂停：叠加半透明遮罩显示「已暂停」，BGM 暂停、计时停止、物理停止。
- 暂停浮层提供「继续」「重玩本关」「返回主菜单」；再按 P / ESC 继续。
- 「重玩本关」需二次确认（「重玩本关？本关进度会丢失」），确认后重载关卡（生命不变、分数清零）。
- 暂停期间不响应移动、跳跃、冲刺、火球键。

### FR-16 音频（P1）

- BGM：按主题播放 `bgm_grass / bgm_cave / bgm_sky / bgm_castle`，循环，切换关卡时切换曲目并淡入 0.3 s。
- 音效 14 个：跳跃、金币、踩敌、顶砖、破砖、变大、变小、火球、死亡、通关、检查点、1UP、菜单、暂停。
- 音乐与音效音量独立控制，0 视为静音；无音频设备时 `Audio.available=False`，所有播放调用安全跳过。
- 暂停只暂停 BGM，短音效自然结束。

### FR-17 视觉反馈与特效（P1）

| 事件 | 特效 |
| --- | --- |
| 顶砖块 | 砖块上弹 8 px / 0.18 s；砖块碎裂 → 4 块碎片抛物线飞散 0.5 s |
| 收集金币 | 金币格 0.2 s 放大旋转上浮 + 「+100」飘字 |
| 踩敌 | 敌人压扁 0.25 s 后消失 + 白色冲击环 |
| 敌人被火球击杀 | 橙色 `poof` 粒子 0.3 s |
| 受伤 | 全屏 1 帧白闪 + 角色闪烁 |
| 通关 | 旗杆降旗 + 分数结算逐项弹出 |
| 火球 | 落地火花粒子（每弹跳一次） |

- 所有特效只影响绘制，不影响碰撞与计分（逻辑即时结算）。

### FR-18 存档与进度（P0）

- 存档路径 `%APPDATA%\SuperTreeio\save.json`，字段见 03 §6.1：

```json
{
  "version": 1,
  "best_score": 4200,
  "coins_total": 137,
  "unlocked": 2,
  "best_times": {"1-1": 95.4},
  "records": [{"score": 4200, "coins": 31, "level": "1-2", "time": "11-25 20:31"}],
  "settings": {"fullscreen": false, "music": 70, "sfx": 80}
}
```

- 读取容错：文件缺失、JSON 损坏、字段类型不符 → 全部降级为默认值，不影响启动。
- 原子写：写 `save.tmp` 后 `os.replace`；写失败只记录，不中断游戏。
- 写入时机：通关结算、返回主菜单、退出、设置项变更。
- `unlocked` 表示已解锁的最大关卡序号（1～4）；`best_times` 为每关最佳通关秒数；`records` 保留前 10。

## 6. 验收标准

1. 干净 Windows 机器双击 exe，3 秒内出窗口，无黑窗、无报错。
2. 主菜单四个入口均可点击，鼠标悬停高亮；开始游戏进入 1-1，角色站在地面上不下沉。
3. 按住 → 时速度在 0.15 s 内升到 320 px/s，松键后约 0.2 s 完全停止；按住 Shift 上限达 460 px/s。
4. 轻按跳跃约 2 格高，全程按住跳跃约 4 格高；离开平台边缘 100 ms 内仍能起跳。
5. 撞墙不抖动、不卡进地形；站立在单向平台上不下落，从下方可穿过。
6. 顶砖块：SMALL 只弹不破，BIG/FIRE 顶碎并 +50 分；顶问号块产出道具并变为已用状态。
7. 踩巡逻菇：敌人消失、玩家弹起、分数按连击 100/200/400/800/1000 递增。
8. 甲壳虫被踩后缩壳，侧碰静止壳可踢出，滑行壳撞死其他敌人。
9. 吃到变大菇变 BIG（碰撞盒 26×56），受伤降为 SMALL 并闪烁 1.2 s；吃火花变 FIRE，X 可发射火球，最多同时 2 颗。
10. 掉坑、尖刺（SMALL）、时间归零均正确扣命；生命 0 进入结算界面。
11. 触碰检查点后死亡，从检查点重生，关卡内金币与敌人全部复位。
12. 抵达旗杆触发通关动画与结算；「下一关」解锁并进入下一关，存档写入正确。
13. 关闭程序再打开，最高分、金币总数、解锁进度、各关最佳用时、音量与显示模式均保持。
14. 破坏 `save.json` 后启动正常，进度归零，不弹报错。
15. 无音频设备时启动不崩溃，游戏可正常进行（仅无声音）。
16. 全屏模式下点击菜单按钮命中正确，点黑边无响应；F11 切换后设置持久化。
17. 同屏 40 个实体时帧率不低于 57 FPS；连续运行 1 小时内存增长 < 80 MB。
18. exe 属性页显示自定义图标、产品名与版本号；4 套主题图、全部精灵图与音频均在包内。

## 7. 需求边界（明确不做）

- 不做联网、云存档、在线排行榜（仅本机前 10）。
- 不做触屏 / 手柄支持（仅键盘 + 鼠标）。
- 不做 Boss 战、多分支地图、隐藏关卡、二周目加难。
- 不做管道传送、水下关卡、飞天状态（P2 暂缓）。
- 不做关卡编辑器（开发期只用文本 JSON 手工编写）。
- 不做自定义按键映射、自定义皮肤包、回放录制。
- 不做多语言（首版中文；代码层可预留）。
- 不做安装包（Inno Setup / MSI），只提供绿色单文件 exe。

## 8. 约束与假设

- 目标机器为 64 位 Windows，屏幕缩放 100%～150% 正常显示；最小可用分辨率 1366×768。
- PyInstaller 必须在 Windows 本机执行，不能跨平台交叉编译。
- pygame 固定 2.5.x / 2.6.x，避免与 PyInstaller 钩子不兼容的旧版本。
- 物理为固定步长 1/120 s 子步，与显示器刷新率无关。
- 所有美术为自制/程序绘制或 AI 生成后处理，音频为程序合成，**不含任天堂官方素材**。
- 名称与商标：`Super Mario`、`Mario` 等为任天堂株式会社的商标与作品名。本项目产品中文名「超级树里奥」、英文名「Super Treeio」为原创命名，玩法借鉴平台跳跃类型通用规则，仅作内部教学示例、非商业分发；正式商业化前须复核名称、角色形象与全部素材的授权状态。
