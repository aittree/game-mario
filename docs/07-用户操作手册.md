## 1. 这是什么

一个 Windows 桌面横版闯关游戏：树里奥从左跑到右，踩敌人、顶砖块、吃道具、躲机关，跑到关底旗杆就算通关。

- 单文件绿色版，双击即玩，**不需要安装**、不需要联网、不需要 Python。
- 键盘操作，自动保存最高分、金币、解锁进度与各关最佳用时。
- 自带 4 个关卡（草原、地下、空中、城堡）、主题背景音乐与音效，可分别调节音量或静音。

## 2. 开始游戏

### 2.1 用 exe（推荐）

1. 双击 `超级树里奥.exe`（首次启动约 1～3 秒，请稍候）。
2. 窗口打开后进入主菜单，点「开始游戏」即可，无需额外设置。

> 若双击没有反应：先确认是否被 Windows 拦截（见 6.1）；onedir 版本请勿单独拷贝 exe，必须保留整个文件夹。

### 2.2 用源码（开发者）

```powershell
conda activate game
python -m pip install pygame
python main.py
```

需要 conda `game` 环境（Python 3.12）与 pygame 2.5+，详见《04-开发规范与环境搭建》。

## 3. 界面说明

```
┌────────────────────────────────────────────────────────────────┐
│ 分数 012800   金币 ×31   1-2   时间 245   生命 ×3              │ ← 顶部信息
├────────────────────────────────────────────────────────────────┤
│                                                                │
│   ▂▂        ?  B B ?      ▄▄▄▄                                 │
│                              ▄▄▄▄                              │
│       ●(巡逻菇)      █(树里奥)          ▲▲▲                     │
│  ████████████   ████        ███████████████████                │
└────────────────────────────────────────────────────────────────┘
```

- **分数**：本局累计得分，来自金币、踩敌、破砖、通关奖励。
- **金币**：本关收集到的金币数；累计 100 枚加一条命（跨关累计，存档保存）。
- **关卡号**（如 `1-2`）：当前关卡，共 4 关。
- **时间**：剩余时间单位，每 0.4 秒减 1；少于 100 时变红闪烁，归零立即失败。
- **生命**：剩余生命次数，初始 3 条。

四个关卡的风格：

| 关卡 | 主题 | 特点 |
| --- | --- | --- |
| 1-1 | 草原 | 教学关：砖块、问号块、金币、巡逻菇、水管、第一个检查点 |
| 1-2 | 地下 | 画面偏暗，尖刺与窄平台多，容错低 |
| 1-3 | 空中 | 大量单向平台与移动平台，飞行蝠出没 |
| 1-4 | 城堡 | 水管花、密集尖刺、长距离跳跃 |

## 4. 操作方法

| 按键 | 作用 |
| --- | --- |
| ← / A | 向左移动 |
| → / D | 向右移动 |
| ↑ / W / 空格 | 跳跃（按住跳更高，松开即开始下落） |
| Shift | 冲刺（按住时跑得更快） |
| ↓ / S | 下蹲（大体型可下穿单向平台） |
| X / F | 发射火球（仅火力状态） |
| P 或 ESC | 暂停 / 继续 |
| F11 | 窗口 / 全屏切换 |
| Enter | 菜单与结算页确认 |
| ESC | 关闭弹窗、子页面返回主菜单 |

### 4.1 跳跃手感说明

- **轻按**跳约 2 格高，**按住**到顶点跳约 4 格高——这是刻意设计，方便你精细控制落点。
- 跑出平台边缘后约 0.11 秒内仍可以起跳（不会「一脚踩空就摔死」）。
- 落地前提前按跳跃，落地瞬间会自动起跳，连跳更顺。

### 4.2 暂停与重开

按 P 或 ESC 暂停，画面出现遮罩，时间停止。暂停界面提供「继续」「重玩本关」「返回主菜单」。重开会二次确认，确认后本关从头开始，生命不变、本关分数清零。

### 4.3 设置

主菜单 →「设置」：

- **音乐音量 / 音效音量**：0～100，步进 10，调完立即生效并自动保存。
- **显示模式**：窗口 / 全屏，等同于 F11（全屏为等比缩放，两侧可能有黑边，不会拉伸变形）。

### 4.4 选关与进度

- 主菜单 →「选择关卡」：显示 4 张关卡卡片与各关最佳用时，未解锁的关卡灰显并带锁图标。
- 「开始游戏」会直接从你已解锁的最高关开始。
- 通关一关即解锁下一关，进度保存在本机。

## 5. 规则与技巧

### 5.1 三种状态

| 状态 | 外观 | 受伤结果 | 能做什么 |
| --- | --- | --- | --- |
| 小 | 矮小 | 直接失败 | 跑、跳、踩敌 |
| 大 | 变高 | 退回小，短暂无敌闪烁 | 顶碎砖块、蹲下穿单向平台 |
| 火力 | 变大 + 变色 | 退回大，短暂无敌闪烁 | 以上全部 + 按 X 发射火球 |

- 吃**变大菇** → 变大；吃**火花** → 火力。
- 受伤后约 1.2 秒无敌（角色闪烁），这段时间撞敌人不扣状态。
- 但**掉进坑里或碰到尖刺**照样算死亡，无敌不保你不掉坑。

### 5.2 敌人

| 敌人 | 长相/行为 | 怎么打 |
| --- | --- | --- |
| 巡逻菇 | 棕色，左右走来走去，走到平台边会掉头 | 从上方踩，或火球 |
| 甲壳虫 | 深色硬壳，走得快 | 踩一下缩成壳；侧碰静止的壳会把它踢飞，滑行的壳能撞死别的敌人；火球也行 |
| 飞行蝠 | 在空中上下摆动飞行 | **只能火球**，踩不到 |
| 水管花 | 从水管里周期性升起 | **只能火球**，升起时碰到会受伤 |

- 只有从**上方落下**踩到敌人才算击杀；从侧面撞上去会受伤。
- 不落地连续踩敌人，分数依次是 100、200、400、800、1000；落地后重新从 100 开始。

### 5.3 地形

- **土块 / 硬块 / 已用问号块**：结实的墙和地，破坏不了。
- **砖块**：小体型顶只会上弹，大体型或火力顶会碎（+50 分）。
- **问号块**：从下面顶一下会出金币、变大菇或火花，用过后变成暗色的空块。
- **单向平台**：可以从下面跳穿上去，站上去后不会掉下来；大体型按住 ↓ 可以从上面穿下去。
- **尖刺**：碰到就受伤（小体型直接失败）。
- **金币**：碰到就收集，+100 分。

### 5.4 生命、检查点与时间

- 初始 3 条命；死亡扣 1 条，并从最近的**检查点**（没有则关卡起点）重来，本关的金币、砖块、敌人全部复位。
- 检查点是关卡中段的旗杆，碰到即记录；一关只记录一次。
- 每关时间从 300 开始，每 0.4 秒减 1；归零即失败。通关时剩余时间会按每单位 10 分折算成奖励分。
- 生命用完 → 本局结束，结算并有机会进入排行榜。

### 5.5 计分

| 行为 | 分数 |
| --- | --- |
| 收集金币 | +100（并累计金币数） |
| 踩敌（连击 1～5+） | 100 / 200 / 400 / 800 / 1000 |
| 火球击杀 | +200 |
| 顶碎砖块 | +50 |
| 顶问号块 | +50 |
| 通关 | 1000 + 剩余时间 × 10 |

### 5.6 玩法技巧

- **提前看脚下**：跳跃高度可变，狭窄平台上轻按一下就够，不必长按。
- **用冲刺跨坑**：普通跑速跨不过 5 格以上的坑，按住 Shift 再跳能多出半格距离。
- **顶砖先变大**：大部分问号块在低处，先吃蘑菇再回来把砖块全部顶碎，能快速攒分。
- **壳可以当武器**：把甲壳虫踩成壳、侧碰踢出去，让它撞死一列敌人，比自己一个个踩更安全。
- **水管花看节奏**：它露出约 1.4 秒、藏起约 1.2 秒，数着节奏通过；火力状态可以在远处用火球清掉。
- **飞行蝠别硬碰**：它不吃踩踏，绕开或等它飞到高点再通过。
- **时间够用但别磨蹭**：120 秒真实时间对 200 格关卡偏紧，重试时优先走主线，不要反复来回捡金币。
- **检查点之后别浪**：检查点只记录一次，但地形会复位，重来后之前顶开的问号块也会恢复，可以再拿一次金币。

## 6. 常见问题

### 6.1 双击后提示「已保护你的电脑」/ 被浏览器或杀软拦截

这是无数字签名程序的 SmartScreen 提示，不代表文件有毒：

- 浏览器下载被拦：下载记录中右键 →「保留」。
- SmartScreen：点「更多信息」→「仍要运行」。
- 企业杀软：把 exe 加入信任目录，或改用文件夹版（onedir）。

### 6.2 启动有几秒延迟

onefile 版本每次启动都要先解压自身，属正常现象。介意可让发布方提供 onedir 文件夹版。

### 6.3 没有声音

- 先检查设置里的「音乐音量」「音效音量」是否为 0；
- 确认系统音量与输出设备正常；
- 若程序在无声卡环境（部分虚拟机、远程桌面）运行，会自动静默运行，游戏本身不受影响。

### 6.4 文字变成方块或问号

字体资源缺失或损坏，请使用完整发布包（onedir 版本勿单独拷 exe）；程序会尝试系统字体兜底，但完整包才能保证显示。

### 6.5 选关页显示「暂不可用」

该关卡的关卡文件缺失或损坏（多见于自行改动程序文件夹）。重新解压完整发布包即可；本机存档与进度不受影响。

### 6.6 最高分、进度突然归零

存档在 `%APPDATA%\SuperTreeio\save.json`。清理系统文件、换 Windows 账户或手动删除该文件都会重置；这是本机存档，不随 exe 走。

### 6.7 按键没反应

确认窗口处于激活状态（先点一下窗口）；若在暂停或结算界面，需要先点「继续」或「下一关」。

### 6.8 跳不上去 / 卡在墙边

- 确认是否按住了跳跃键（长按跳更高）；
- 贴墙起跳时先松一下方向键再跳，避免起跳瞬间被墙「蹭」掉一段上升速度；
- 若角色明显卡进地形，这是程序问题，请按第 8 节反馈。

### 6.9 角色变小后从缝隙里掉下去

小体型比大体型矮一半，原来能站住的位置可能会掉下去；这是设计使然。遇到窄缝先吃蘑菇变大再通过，或者直接跳过。

## 7. 卸载与清理

本程序不写注册表、不装服务：

1. 删除 `超级树里奥.exe`（或整个程序文件夹）。
2. 如需清空纪录与进度，删除 `%APPDATA%\SuperTreeio\` 文件夹。

## 8. 反馈问题时请提供

- 使用的版本（exe 属性页「详细信息」中的版本号）
- Windows 版本与屏幕缩放比例
- 问题现象与复现步骤（哪一关、大概第几格、是否全屏、是否静音）
- 若是卡地形或穿墙，尽量附上角色当时的屏幕位置
- 若崩溃，附 `%APPDATA%\SuperTreeio\crash.log`（如果存在）
