### 2.1 关卡 JSON 结构

字段约定：

| 字段 | 类型 | 约束 |
| --- | --- | --- |
| `id` | str | 与文件名一致（`w1-1.json` → `1-1`），用于存档键 |
| `name` | str | 选关与 HUD 显示 |
| `theme` | str | 必须是 `config.THEMES` 的键 |
| `cols` / `rows` | int | `rows` 固定 18；`cols` 160～200 |
| `time` | int | 时间单位，默认 300 |
| `spawn` | [col, row] | 玩家脚底落在该格底面；该格及其上方 1 格必须为空 |
| `tiles` | list[str] | 长度 = rows，每行长度 = cols，仅允许 2.1 表中的图块码 |
| `items` | dict[str, str] | 键 `"col,row"` 必须指向 `?` 问号块；值 `coin/mushroom/flower` |
| `entities` | list[dict] | `type` 必须在下表内；`col/row` 在边界内 |

图块码表：

| 码 | 名称 | 实心 | 说明 |
| --- | --- | --- | --- |
| `.` | 空 | 否 | 空气 |
| `#` | 土块 | 是 | 地面主体，不可破坏 |
| `B` | 砖块 | 是 | BIG/FIRE 顶碎，SMALL 只顶弹 |
| `M` | 硬块 | 是 | 不可破坏 |
| `?` | 问号块 | 是 | 顶一次变 `X` 并产出 `items` 指定内容 |
| `X` | 已用块 | 是 | 问号块使用后 |
| `P` | 水管 | 是 | 实心，渲染时按邻居自动选图 |
| `=` | 单向平台 | 半 | 只能从上站立，可下穿 |
| `^` | 尖刺 | 否 | 接触受伤 |
| `c` | 金币 | 否 | 重叠即收集，收集后变空 |

实体类型表：

| type | 说明 | 额外字段 |
| --- | --- | --- |
| `patrol_shroom` | 巡逻菇 | — |
| `shellbug` | 甲壳虫 | — |
| `flitter` | 飞行蝠 | `amp`（默认 60）、`period`（默认 2.4） |
| `pipe_bloom` | 水管花 | 放置格必须是水管顶格 |
| `moving_platform` | 移动平台 | `path`（≥2 个格点）、`speed` |
| `checkpoint` | 检查点 | — |
| `goal` | 终点旗杆 | — |

> 设计取舍：金币、砖块、尖刺都放在**地形网格**里而不是实体列表，因为它们不需要独立生命周期（收集后改一格、破坏后改一格即可），这样关卡文件更短、逐帧遍历更快；敌人、道具、平台、检查点、终点需要独立状态，才进实体列表。

### 2.2 解析与校验

```python
class LevelError(Exception):
    """关卡文件不可用。main 捕获后把该关标记为不可用。"""

CODE_SET = set(EMPTY + GROUND + BRICK + METAL + QUESTION + USED + PIPE + PLATFORM + SPIKE + COIN)
ENTITY_TYPES = {"patrol_shroom", "shellbug", "flitter", "pipe_bloom",
                "moving_platform", "checkpoint", "goal"}

class TileMap:
    def __init__(self, rows: int, cols: int, grid: list[list[str]], theme: str):
        self.rows, self.cols, self.grid, self.theme = rows, cols, grid, theme

    # —— 构造 ——
    @classmethod
    def from_dict(cls, data: dict) -> "TileMap":
        rows, cols = int(data.get("rows", VIEW_ROWS)), int(data["cols"])
        if rows != VIEW_ROWS:
            raise LevelError(f"rows 必须为 {VIEW_ROWS}")
        lines = data["tiles"]
        if len(lines) != rows:
            raise LevelError("tiles 行数不符")
        grid = []
        for i, line in enumerate(lines):
            if len(line) != cols:
                raise LevelError(f"第 {i} 行长度 {len(line)} != {cols}")
            bad = set(line) - CODE_SET
            if bad:
                raise LevelError(f"第 {i} 行含未知图块码 {bad}")
            grid.append(list(line))
        theme = data["theme"]
        if theme not in THEMES:
            raise LevelError(f"未知主题 {theme}")
        return cls(rows, cols, grid, theme)

    @classmethod
    def from_file(cls, path: str) -> "TileMap":
        import json
        try:
            with open(path, "r", encoding="utf-8") as f:
                data = json.load(f)
        except (OSError, ValueError) as exc:
            raise LevelError(str(exc)) from exc
        return cls.from_dict(data)

    # —— 尺寸 ——
    @property
    def width_px(self) -> int:
        return self.cols * TILE

    @property
    def height_px(self) -> int:
        return self.rows * TILE

    # —— 查询 ——
    def tile_at(self, col: int, row: int) -> str:
        if 0 <= row < self.rows and 0 <= col < self.cols:
            return self.grid[row][col]
        return EMPTY

    def solid(self, col: int, row: int) -> bool:
        """左右越界视为实心墙，把玩家挡在关卡内；上方越界为空；下方越界为空（掉出去即死）。"""
        if col < 0 or col >= self.cols:
            return True
        if row < 0 or row >= self.rows:
            return False
        return self.grid[row][col] in SOLID_TILES

    def semisolid(self, col: int, row: int) -> bool:
        return 0 <= row < self.rows and 0 <= col < self.cols \
            and self.grid[row][col] in SEMISOLID_TILES

    def hazard(self, col: int, row: int) -> bool:
        return 0 <= row < self.rows and 0 <= col < self.cols \
            and self.grid[row][col] in HAZARD_TILES

    def coin(self, col: int, row: int) -> bool:
        return 0 <= row < self.rows and 0 <= col < self.cols \
            and self.grid[row][col] == COIN_TILE

    # —— 修改（仅模型层调用）——
    def take_coin(self, col: int, row: int) -> bool:
        if self.coin(col, row):
            self.grid[row][col] = EMPTY
            return True
        return False

    def remove(self, col: int, row: int) -> None:
        if 0 <= row < self.rows and 0 <= col < self.cols:
            self.grid[row][col] = EMPTY

    def use_question(self, col: int, row: int) -> None:
        if self.tile_at(col, row) == QUESTION:
            self.grid[row][col] = USED
```

**实现要点**

- `solid()` 对 `col` 越界返回 `True`：这等于给关卡左右各加了一堵看不见的墙，玩家永远走不出画面，也免去在主循环里检查边界。
- `solid()` 对 `row >= rows` 返回 `False`：掉到关卡下方会一直下落，由会话在 `y > height_px + 200` 时判定死亡，而不是卡在底部。
- 所有修改方法（`take_coin/remove/use_question`）只允许 `game.py` 调用；`ui/*` 只读。
- 解析阶段一次性把「非法图块码、行长度不符」挡掉，运行时不再做容错判断，热路径更快。

## 3. 物理与碰撞（`src/physics.py`）

### 3.1 数据结构

```python
from dataclasses import dataclass, field

@dataclass
class Body:
    x: float          # 左上角世界坐标（px）
    y: float
    w: float
    h: float
    vx: float = 0.0
    vy: float = 0.0

    @property
    def aabb(self) -> tuple[float, float, float, float]:
        return (self.x, self.y, self.x + self.w, self.y + self.h)

    @property
    def bottom(self) -> float:
        return self.y + self.h

@dataclass
class Contacts:
    left: bool = False
    right: bool = False
    head: bool = False
    ground: bool = False
    head_tiles: list[tuple[int, int]] = field(default_factory=list)

def overlap(a: Body | tuple, b: Body | tuple) -> bool:
    ax0, ay0, ax1, ay1 = a.aabb if isinstance(a, Body) else a
    bx0, by0, bx1, by1 = b.aabb if isinstance(b, Body) else b
    return ax0 < bx1 and bx0 < ax1 and ay0 < by1 and by0 < ay1
```

### 3.2 瓦片重叠区间

```python
import math
from .config import TILE, VIEW_ROWS

def span(body: Body) -> tuple[int, int, int, int]:
    """返回体当前覆盖的瓦片列/行区间（含端点）。用 1e-6 内缩，避免贴边时把相邻格算进来。"""
    c0 = math.floor(body.x / TILE)
    c1 = math.floor((body.x + body.w - 1e-6) / TILE)
    r0 = math.floor(body.y / TILE)
    r1 = math.floor((body.y + body.h - 1e-6) / TILE)
    return c0, c1, r0, r1
```

### 3.3 移动与解算（核心）

```python
def move_and_collide(body: Body, tmap, dt: float,
                     drop_through: bool = False) -> Contacts:
    """先水平、后垂直，分别贴边。drop_through=True 时忽略单向平台（按下键下穿）。"""
    contacts = Contacts()
    prev_bottom = body.bottom

    # ——— 水平 ———
    if body.vx:
        body.x += body.vx * dt
        c0, c1, r0, r1 = span(body)
        if body.vx > 0:
            hit = [c for c in range(c0, c1 + 1)
                   if any(tmap.solid(c, r) for r in range(r0, r1 + 1))]
            if hit:
                body.x = min(hit) * TILE - body.w      # 贴住最左的实心格
                body.vx = 0.0
                contacts.right = True
        else:
            hit = [c for c in range(c1, c0 - 1, -1)
                   if any(tmap.solid(c, r) for r in range(r0, r1 + 1))]
            if hit:
                body.x = (max(hit) + 1) * TILE
                body.vx = 0.0
                contacts.left = True

    # ——— 垂直 ———
    if body.vy:
        body.y += body.vy * dt
        c0, c1, r0, r1 = span(body)
        cols = range(max(0, c0), min(tmap.cols, c1 + 1))
        if body.vy > 0:                                  # 下落
            rows = [r for r in range(r0, r1 + 1)
                    if any(tmap.solid(c, r) for c in cols)
                    or (not drop_through
                        and any(tmap.semisolid(c, r) for c in cols)
                        and prev_bottom <= r * TILE + 0.5)]
            if rows:
                body.y = min(rows) * TILE - body.h
                body.vy = 0.0
                contacts.ground = True
        else:                                            # 上升
            rows = [r for r in range(r1, r0 - 1, -1)
                    if any(tmap.solid(c, r) for c in cols)]
            if rows:
                row = max(rows)
                body.y = (row + 1) * TILE
                body.vy = 0.0
                contacts.head = True
                contacts.head_tiles = [(c, row) for c in cols
                                       if tmap.solid(c, row)]
    return contacts
```

**为什么必须先水平后垂直，且分轴解算**

- 若一次性按速度向量做斜向检测，贴墙下落时会被墙顶「顶一下」，出现每秒十几次的抖动；分轴解算每次只处理一个方向，贴墙就是贴墙。
- 水平解算用「最左/最右命中的实心列」而不是逐格回退：一帧位移最多 460/120 ≈ 3.8 px，远小于瓦片 40 px，因此命中列唯一确定，计算一次即可。
- 垂直解算必须记住 `prev_bottom`：单向平台只在「上一帧脚底不低于平台顶面」时生效，否则从下方跳上来会被卡住。
- 上升时把命中的整行图块全部上报（`head_tiles`），顶到两块相邻砖块时两块都要弹。

### 3.4 单向平台载人与地面探测

```python
def standing_on(body: Body, tmap) -> bool:
    """脚底正好压在实心或单向平台顶面上（误差 1.5 px），用于动画与土狼时间。"""
    c0, c1, _, _ = span(body)
    row = int(round((body.bottom) / TILE))
    for c in range(max(0, c0), min(tmap.cols, c1 + 1)):
        if tmap.solid(c, row) or tmap.semisolid(c, row):
            return True
    return False
```

> 只用于「视觉与土狼计时」的主观判断。真正的站立由 `move_and_collide` 返回的 `contacts.ground` 决定，避免贴边误差造成土狼时间被错误续期。

实体坐标约定：`x, y` 是**左上角**；生成时由格坐标换算：

```python
def place_at(col: int, row: int, w: float, h: float, bottom_aligned: bool = True) -> tuple[float, float]:
    """把宽度 w、高度 h 的实体放在 (col,row) 格内；bottom_aligned 时脚底贴齐该格底面。"""
    x = col * TILE + (TILE - w) / 2
    y = (row + 1) * TILE - h if bottom_aligned else row * TILE
```

#### 4.2.1 每步推进

```python
    def update(self, dt: float, intent: InputIntent, world: WorldView) -> Contacts:
        if self.dead:
            self._update_dead(dt)
            return Contacts()

        self._tick_timers(dt)
        self._horizontal(dt, intent)
        self._vertical(dt, intent)
        self._try_fire(intent)

        # 位移与地形解算（按下 ↓ 且为大体型时允许下穿单向平台）
        drop = intent.down and self.power is not PowerState.SMALL
        contacts = move_and_collide(self.body, world.tilemap, dt, drop_through=drop)

        if contacts.ground:
            self.on_ground = True
            self.stomp_chain = 0
        elif self.body.vy > 0:
            self.on_ground = False
        if self.on_ground and not standing_on(self.body, world.tilemap):
            self.on_ground = False          # 走出平台边缘的下一帧即离地

        # 土狼时间
        if self.on_ground:
            self.coyote_ms = COYOTE_MS
        else:
            self.coyote_ms = max(0.0, self.coyote_ms - dt * 1000)

        self._pick_anim(intent)
        return contacts
```

```python
    def _tick_timers(self, dt: float):
        ms = dt * 1000
        self.invincible_ms = max(0.0, self.invincible_ms - ms)
        self.transform_ms = max(0.0, self.transform_ms - ms)
        self.fire_cd_ms = max(0.0, self.fire_cd_ms - ms)
        self.buffer_ms = max(0.0, self.buffer_ms - ms)
        self.anim_timer += dt

    def _horizontal(self, dt: float, intent: InputIntent):
        dir_in = (1 if intent.right else 0) - (1 if intent.left else 0)
        target = MAX_SPRINT if intent.sprint else MAX_WALK

        if dir_in:
            self.facing = dir_in
            if self.on_ground and self.body.vx * dir_in < 0:
                acc = SKID_DEC                      # 反向：先刹车
            elif self.on_ground:
                acc = SPRINT_ACC if intent.sprint else GROUND_ACC
            else:
                acc = AIR_ACC
            self.body.vx += dir_in * acc * dt
        else:
            if self.on_ground:
                self._decay(FRICTION * dt)           # 地面摩擦
            else:
                self._decay(FRICTION * 0.35 * dt)    # 空中阻力很小

        # 限制到当前上限；上限降低时用摩擦平滑收敛，不瞬间掉速
        if abs(self.body.vx) > target:
            self.body.vx = math.copysign(
                max(target, abs(self.body.vx) - FRICTION * dt), self.body.vx)
        self.body.vx = max(-MAX_SPRINT, min(MAX_SPRINT, self.body.vx))

    def _decay(self, amount: float):
        if self.body.vx > 0:
            self.body.vx = max(0.0, self.body.vx - amount)
        elif self.body.vx < 0:
            self.body.vx = min(0.0, self.body.vx + amount)
```

```python
    def _vertical(self, dt: float, intent: InputIntent):
        # 跳跃缓冲
        if intent.jump_pressed:
            self.buffer_ms = JUMP_BUFFER_MS
        # 起跳条件：有缓冲 + （在地面 或 土狼时间内）
        if self.buffer_ms > 0 and (self.on_ground or self.coyote_ms > 0):
            self.body.vy = -JUMP_VEL
            self.on_ground = False
            self.coyote_ms = 0.0
            self.buffer_ms = 0.0
            self.events.append("jump")

        # 可变跳跃高度：松开跳跃键时裁剪上升速度
        if (not intent.jump_held) and self.body.vy < -JUMP_VEL * JUMP_CUT:
            self.body.vy = -JUMP_VEL * JUMP_CUT

        self.body.vy = min(self.body.vy + GRAVITY * dt, MAX_FALL)
```

```python
    def _try_fire(self, intent: InputIntent):
        if not intent.fire_pressed:
            return
        if self.power is not PowerState.FIRE or self.fire_cd_ms > 0:
            return
        self.fire_cd_ms = FIRE_COOLDOWN_MS
        cx = self.body.x + self.body.w / 2
        cy = self.body.y + self.body.h * 0.4
        self.spawn_requests.append(("fireball", cx, cy, self.facing))
        self.events.append("fire")

    def _pick_anim(self, intent: InputIntent):
        if self.transform_ms > 0:
            self.anim = AnimState.GROW
        elif self.invincible_ms > 0:
            self.anim = AnimState.HURT
        elif not self.on_ground:
            self.anim = AnimState.JUMP if self.body.vy < 0 else AnimState.FALL
        elif intent.down and self.power is not PowerState.SMALL and abs(self.body.vx) < 1:
            self.anim = AnimState.CROUCH
        elif abs(self.body.vx) > 20 and (intent.left or intent.right):
            if self.on_ground and self.body.vx * ((1 if intent.right else 0)
                                                  - (1 if intent.left else 0)) < 0:
                self.anim = AnimState.SKID
            else:
                self.anim = AnimState.RUN
        else:
            self.anim = AnimState.IDLE
```

#### 4.2.2 踩踏、受伤、变形、死亡

```python
    def can_stomp(self, enemy) -> bool:
        """玩家下落、脚部进入敌人头上 12 px 带，且水平重叠 ≥ 6 px。"""
        if self.body.vy <= 0:
            return False
        top = enemy.body.y
        if not (top - 12 <= self.body.bottom <= top + 12):
            return False
        ox = min(self.body.x + self.body.w, enemy.body.x + enemy.body.w) \
            - max(self.body.x, enemy.body.x)
        return ox >= 6

    def bounce(self):
        self.body.vy = -STOMP_BOUNCE
        self.on_ground = False
        self.coyote_ms = 0.0

    def hurt(self, source: str = "contact") -> str:
        """返回结果：'none'（无敌/变形中） / 'shrink' / 'die'。"""
        if self.invincible_ms > 0 or self.transform_ms > 0:
            return "none"
        if self.power is PowerState.FIRE:
            self.power = PowerState.BIG
            self._enter_hurt()
            return "shrink"
        if self.power is PowerState.BIG:
            self.power = PowerState.SMALL
            self._enter_hurt()
            return "shrink"
        self.kill()
        return "die"

    def _enter_hurt(self):
        self._apply_size()
        self.invincible_ms = INVINCIBLE_MS
        self.transform_ms = TRANSFORM_MS
        self.events.append("hurt")

    def grow(self, to_fire: bool = False) -> bool:
        """吃道具：返回是否真的发生变化（用于计分）。"""
        if to_fire:
            if self.power is PowerState.FIRE:
                return False
            self.power = PowerState.FIRE
        else:
            if self.power is not PowerState.SMALL:
                return False
            self.power = PowerState.BIG
        self._apply_size()
        self.transform_ms = TRANSFORM_MS
        self.invincible_ms = max(self.invincible_ms, TRANSFORM_MS)
        self.events.append("grow")
        return True

    def kill(self):
        if self.dead:
            return
        self.dead = True
        self.anim = AnimState.DEAD
        self.anim_timer = 0.0
        self.body.vx = 0.0
        self.body.vy = -520.0
        self.events.append("death")

    def _update_dead(self, dt: float):
        self.anim_timer += dt
        self.body.vy = min(self.body.vy + GRAVITY * dt, MAX_FALL)
        self.body.y += self.body.vy * dt       # 死亡后忽略地形，直接落出画面
```

**关键点**

- `hurt()` 只在 `invincible_ms == 0` 且 `transform_ms == 0` 时生效，避免同一次接触在多步物理里连续掉级。
- `grow()` 后立刻 `_apply_size()` 并把脚底对齐，若头被地形压住会发生「顶进地形」——因此 `grow` 之后由会话调用一次 `push_out_of_tiles()`（§4.3）纠正。
- 死亡使用忽略地形的自由落体，保证一定落出画面，不会卡在坑里。

### 4.3 顶出地形纠正

```python
def push_out_of_tiles(body: Body, tmap) -> None:
    """体型变大后若与实心格重叠，逐格向上顶出（最多 3 格），仍重叠则改为向左/右挪。"""
    for _ in range(3):
        c0, c1, r0, r1 = span(body)
        hits = [(r, c) for r in range(r0, r1 + 1) for c in range(c0, c1 + 1)
                if tmap.solid(c, r)]
        if not hits:
            return
        body.y = min(r for r, _ in hits) * TILE - body.h - 0.01
```

```python
            self.state = "shell_idle"
            self.body.h = 24
            self.body.y += 10
        elif self.state == "shell_slide":
            self.state = "shell_idle"          # 踩滑行的壳 = 刹车
```

### 6.3 固定步长推进

```python
    def step(self, intent: InputIntent, dt: float):
        """dt 恒为 PHYSICS_DT；所有时间与物理推进都在这里。"""
        if self.state is SessionState.FAILED:
            return
        if self.state is SessionState.DYING:
            self._step_dying(dt)
            return
        if self.state is SessionState.CLEARED:
            self._step_clear(dt)
            return

        world = WorldView(self.tilemap, self.camera.x,
                          self.player.body.x, self.tilemap.width_px)

        # 1. 玩家
        contacts = self.player.update(dt, intent, world)
        self._drain_player_output()
        for col, row in contacts.head_tiles:
            self.handle_bump(col, row)

        # 2. 敌人
        for e in self.enemies:
            if not e.alive:
                continue
            if not e.active and e.body.x < self.camera.x + VIEW_COLS * TILE + 200:
                e.active = True
            e.update(dt, world)

        # 3. 道具与机关
        for i in self.items:
            if i.alive:
                i.update(dt, world)

        # 4. 平台载人（先于接触结算）
        self._update_props(dt, world)

        # 5. 接触结算
        self._resolve_player_tiles()
        self._resolve_entities()
        self._resolve_fireballs()

        # 6. 计时与镜头
        self._tick_time(dt)
        self.camera.follow(self.player.body.x, dt)

        # 7. 死亡与通关判定
        if self.player.body.y > self.tilemap.height_px + 200:
            self.player.kill()
        if self.player.dead and self.state is SessionState.RUNNING:
            self.state = SessionState.DYING
            self.death_ms = 0.0
        if self.goal and self.goal.touched and self.state is SessionState.RUNNING:
            self._begin_clear()
```

### 6.4 接触结算

```python
    def _resolve_player_tiles(self):
        c0, c1, r0, r1 = span(self.player.body)
        for r in range(r0, r1 + 1):
            for c in range(c0, c1 + 1):
                if self.tilemap.coin(c, r):
                    self.tilemap.take_coin(c, r)
                    self._add_coin(1)
                elif self.tilemap.hazard(c, r):
                    self._player_hurt("hazard")
```

> 金币用「重叠格」判定而不是像素距离：金币格本身就是 40×40，玩家碰到即收，符合手感且无需额外实体。

```python
    def _resolve_entities(self):
        player = self.player
        for e in self.enemies:
            if not e.alive or not overlap(player.body, e.body):
                continue
            if player.can_stomp(e) and e.on_stomp():
                player.bounce()
                self.score += stomp_score(player.stomp_chain)
                player.stomp_chain += 1
                self.events.append(GameEvent("stomp", {"kind": e.kind, "cells": e.aabb}))
            elif isinstance(e, Shellbug) and e.state == "shell_idle" and player.invincible_ms == 0:
                e.kick(1 if e.body.x > player.body.x else -1)
                self.events.append(GameEvent("stomp", {"kind": "shell_kick", "cells": e.aabb}))
            else:
                self._player_hurt("enemy")

        # 滑行壳撞其它敌人
        for shell in (e for e in self.enemies if isinstance(e, Shellbug) and e.state == "shell_slide"):
            for other in self.enemies:
                if other is shell or not other.alive or not overlap(shell.body, other.body):
                    continue
                other.alive = False
                self.score += SCORE_FIREKILL
                self.events.append(GameEvent("stomp", {"kind": other.kind, "cells": other.aabb}))

        # 道具拾取
        for item in self.items:
            if not item.alive or item.emerge_ms > 0 or not overlap(player.body, item.body):
                continue
            if isinstance(item, Fireball):
                continue
            item.alive = False
            changed = player.grow(to_fire=isinstance(item, FireFlower))
            self.score += 100 if not changed else 0
            self.events.append(GameEvent("powerup", {"type": item.kind}))
            push_out_of_tiles(player.body, self.tilemap)

        # 检查点与终点
        for p in self.props:
            if isinstance(p, Checkpoint) and not p.raised and overlap(player.body, p.body):
                p.raised = True
                col = int((p.body.x + p.body.w / 2) // TILE)
                self.checkpoint = (col, int(p.body.bottom // TILE) - 1)
                self.events.append(GameEvent("checkpoint"))
            if isinstance(p, Goal) and not p.touched and overlap(player.body, p.body):
                p.touched = True
```

### 6.5 死亡、重生、通关

```python
    def _step_dying(self, dt: float):
        self.death_ms += dt * 1000
        self.player.update(dt, InputIntent(), WorldView(self.tilemap, 0, 0,
                                                        self.tilemap.width_px))
        if self.death_ms < DEATH_MS:
            return
        self.lives -= 1
        if self.lives <= 0:
            self.state = SessionState.FAILED
            self.events.append(GameEvent("gameover"))
            return
        self.state = SessionState.RUNNING
        self._build_world()                      # 整关重载：地形/敌人/金币全部复位
        self.player.invincible_ms = RESPAWN_INVINCIBLE_MS
        self.camera.snap_to(self.player.body.x)

    def _begin_clear(self):
        self.state = SessionState.CLEARED
        self.clear_ms = 0.0
        self.player.body.vx = 0
        self.player.body.vy = 0
        bonus = SCORE_CLEAR_FIXED + time_to_score(self.time_units)
        self.score += bonus
        self.clear_bonus = bonus
        self.events.append(GameEvent("clear", {"bonus": bonus, "time": self.time_units,
                                               "coins": self.coins}))

    def _step_clear(self, dt: float):
        self.clear_ms += dt * 1000
        if self.clear_ms <= CLEAR_SLIDE_MS:            # 沿杆下滑
            self.player.body.y = min(self.player.body.y + 120 * dt,
                                     (self.goal.body.y + self.goal.body.h) - self.player.body.h)
            if self.goal:
                self.goal.flag_y = min(1.0, self.clear_ms / CLEAR_SLIDE_MS)
```

```python
    def _release_item(self, col: int, row: int):
```

## 7. 相机（`src/camera.py`）

```python
class Camera:
    def __init__(self, level_width: int):
        self.x = 0.0
        self.level_width = level_width
        self.max_x = max(0, level_width - CANVAS_W)

    def snap_to(self, player_x: float):
        self.x = self._clamp(player_x - CANVAS_W * 0.45)

    def follow(self, player_x: float, dt: float):
        screen_x = player_x - self.x
        if screen_x < CAM_DEAD_MIN * CANVAS_W:
            target = player_x - CAM_DEAD_MIN * CANVAS_W
        elif screen_x > CAM_DEAD_MAX * CANVAS_W:
            target = player_x - CAM_DEAD_MAX * CANVAS_W
        else:
            return
        # 目标位置硬钳制，再小幅插值，避免高速冲刺时相机抖动
        self.x += (self._clamp(target) - self.x) * min(1.0, CAM_LERP * 60 * dt)

    def _clamp(self, x: float) -> float:
        return max(0.0, min(self.max_x, x))

    def to_screen(self, world_x: float) -> float:
        return world_x - self.x

    def parallax(self, factor: float) -> float:
        """背景层偏移：factor 越小越远。"""
        return -self.x * factor
```

> `follow` 中先用目标钳制再插值：如果先插值再钳制，镜头会在关卡末尾「过冲」再被拉回，出现橡皮筋效果。

### 8.3 音频（`src/audio.py`）

```python
SFX_FILES = {
    "jump": "sfx_jump.wav", "coin": "sfx_coin.wav", "stomp": "sfx_stomp.wav",
    "bump": "sfx_bump.wav", "brick": "sfx_brick.wav", "powerup": "sfx_powerup.wav",
    "powerdown": "sfx_powerdown.wav", "fire": "sfx_fire.wav", "death": "sfx_death.wav",
    "clear": "sfx_clear.wav", "checkpoint": "sfx_checkpoint.wav", "oneup": "sfx_oneup.wav",
    "menu": "sfx_menu.wav", "pause": "sfx_pause.wav",
}
BGM_FILES = {
    "grass": "bgm_grass.wav", "cave": "bgm_cave.wav",
    "sky": "bgm_sky.wav", "castle": "bgm_castle.wav",
}

class Audio:
    def __init__(self, music_volume=70, sfx_volume=80):
        self.available = False
        self.sounds, self.music_volume, self.sfx_volume = {}, music_volume, sfx_volume
        self.current_bgm = None
        try:
            pygame.mixer.init(frequency=22050, size=-16, channels=1, buffer=512)
            self.available = True
        except pygame.error:
            return                                  # 无声卡：所有调用降级为空操作
        for key, name in SFX_FILES.items():
            try:
                self.sounds[key] = pygame.mixer.Sound(
                    resource_path("assets", "audio", name))
            except (pygame.error, FileNotFoundError):
                continue                            # 缺单个音效不影响其他
        pygame.mixer.music.set_volume(self.music_volume / 100)

    def play(self, name: str):
        if not self.available or self.sfx_volume == 0:
            return
        snd = self.sounds.get(name)
        if snd:
            snd.set_volume(self.sfx_volume / 100)
            snd.play()

    def play_bgm(self, key: str):
        """切主题 BGM：同一首不重播；切换时淡入由 mixer 音量过渡完成。"""
        if not self.available or key == self.current_bgm:
            return
        try:
            pygame.mixer.music.load(resource_path("assets", "audio", BGM_FILES[key]))
        except (pygame.error, FileNotFoundError, KeyError):
            self.current_bgm = None
            return
        pygame.mixer.music.set_volume(self.music_volume / 100)
        pygame.mixer.music.play(-1)
        self.current_bgm = key

    def pause(self):
        if self.available:
            pygame.mixer.music.pause()

    def resume(self):
        if self.available and self.music_volume > 0:
            pygame.mixer.music.unpause()
```

要点：

- BGM 用 `pygame.mixer.music`（单通道，天然「同时只有一首」），音效走 `Sound.play()` 自动分配通道，找不到空闲通道就丢弃，不排队。
- 音量 0 时 `play()` 直接返回，`music.set_volume(0)`；从 0 调回时调用 `unpause()`。
- 关卡切换时调用 `play_bgm(theme["bgm"])`，`current_bgm` 相同则不重播，避免同一主题连续两关音乐从头开始。

### 8.4 按键映射（`src/keymap.py`）

```python
import pygame

from .entities.base import InputIntent   # 仅导入纯数据类型，不依赖实体业务逻辑

MOVE_LEFT = (pygame.K_LEFT, pygame.K_a)
MOVE_RIGHT = (pygame.K_RIGHT, pygame.K_d)
JUMP = (pygame.K_UP, pygame.K_w, pygame.K_SPACE)
SPRINT = (pygame.K_LSHIFT, pygame.K_RSHIFT)
FIRE = (pygame.K_x, pygame.K_f)
DOWN = (pygame.K_DOWN, pygame.K_s)

class Keymap:
    def __init__(self):
        self.held = set()
        self._jump_pressed = False
        self._fire_pressed = False

    def keydown(self, key: int) -> bool:
        """返回 True 表示本模块消费了该键（界面键由 main 处理）。"""
        self.held.add(key)
        if key in JUMP:
            self._jump_pressed = True
        if key in FIRE:
            self._fire_pressed = True
        return key in (MOVE_LEFT + MOVE_RIGHT + JUMP + SPRINT + FIRE + DOWN)

    def keyup(self, key: int):
        self.held.discard(key)

    def sample(self) -> InputIntent:
        intent = InputIntent(
            left=any(k in self.held for k in MOVE_LEFT),
            right=any(k in self.held for k in MOVE_RIGHT),
            jump_held=any(k in self.held for k in JUMP),
            sprint=any(k in self.held for k in SPRINT),
            down=any(k in self.held for k in DOWN),
            jump_pressed=self._jump_pressed,
            fire_pressed=self._fire_pressed,
        )
        self._jump_pressed = self._fire_pressed = False   # 边沿只生效一帧
        return intent

    def clear(self):
        """切界面时清空按住状态，防止回到游戏后「继续按住」。"""
        self.held.clear()
        self._jump_pressed = self._fire_pressed = False
```

> 按键边沿必须「采样即清」：同一帧内物理子步共享同一份 `InputIntent`，所以一次按键只产生一次跳跃/火球，不会因为执行了 2～6 个物理步而连跳。

绘制顺序（严格按此，后绘制覆盖前者）：

1. 天空底色（主题渐变）+ 远景层 `far`（视差 0.35）+ 近景层 `near`（视差 0.7）。
2. 地形：只遍历相机可见列 `[cam//TILE - 1, +33]`，逐格绘制；`?` 块与 `c` 金币按时间取帧。
3. 实体（敌人/道具/平台/检查点/终点），按 `y` 从大到小排序（下方的先画，制造正确遮挡）。
4. 玩家（含无敌闪烁：每 60 ms 跳过一帧绘制）。
5. 火球与粒子特效。
6. 顶砖偏移：绘制地形时按 `effects.bump_offset(col, row)` 位移 0～8 px。
7. HUD（不随相机移动）。
8. 浮层（暂停/结算）。

```python
    def _draw_tiles(self, surf, snap, effects):
        tmap, cam = snap.tilemap, snap.camera_x
        c_start = max(0, int(cam // TILE) - 1)
        c_end = min(tmap.cols, c_start + VIEW_COLS + 2)
        for row in range(tmap.rows):
            for col in range(c_start, c_end):
                code = tmap.grid[row][col]
                if code == EMPTY:
                    continue
                frame = self._tile_frame(snap.theme, code, row, col, tmap, snap.time_units)
                dx, dy = effects.bump_offset(col, row)
                surf.blit(frame, (col * TILE - int(cam) + dx, row * TILE + dy))
```

`_tile_frame` 的自动拼接规则（水管统一做成 2 格宽，因此只有「左段 / 右段 / 单格」三种管口）：

```python
def pipe_frame(tmap, col, row):
    """水管：上面还是管 → 管身帧；否则按左右邻居选管口帧。"""
    if tmap.solid(col, row - 1):
        return 6                       # 管身
    has_left = tmap.tile_at(col - 1, row) == PIPE
    has_right = tmap.tile_at(col + 1, row) == PIPE
    if has_right:
        return 7                       # 2 格宽管口的左半
    if has_left:
        return 8                       # 2 格宽管口的右半
    return 9                           # 单列管口
```

> 图块集 16 帧的索引定义见 08 §2.3，渲染代码必须与索引表严格对应；金币帧则由动画计时器驱动（4 帧循环 0.4 s），与关卡剩余时间无关。

### 9.5 显示层（`display.py`）

```python
class Display:
    def __init__(self, fullscreen: bool):
        self.canvas = pygame.Surface((CANVAS_W, CANVAS_H)).convert()
        self.apply_mode(fullscreen)

    def apply_mode(self, fullscreen: bool):
        self.fullscreen = fullscreen
        if fullscreen:
            self.screen = pygame.display.set_mode((0, 0), pygame.FULLSCREEN)
            sw, sh = self.screen.get_size()
            self.scale = min(sw / CANVAS_W, sh / CANVAS_H)
            w, h = int(CANVAS_W * self.scale), int(CANVAS_H * self.scale)
            self.scaled = pygame.Surface((w, h))
            self.offset = ((sw - w) // 2, (sh - h) // 2)
        else:
            dw, dh = pygame.display.get_desktop_sizes()[0]
            self.scale = min(1.0, (dw - 40) / CANVAS_W, (dh - 120) / CANVAS_H)
            w, h = int(CANVAS_W * self.scale), int(CANVAS_H * self.scale)
            self.screen = pygame.display.set_mode((w, h))
            self.scaled = pygame.Surface((w, h)) if self.scale < 1.0 else None
            self.offset = (0, 0)

    def present(self):
        if self.scaled is not None:
            pygame.transform.smoothscale(self.canvas, self.scaled.get_size(), self.scaled)
            if self.fullscreen:
                self.screen.fill((0, 0, 0))
                self.screen.blit(self.scaled, self.offset)
            else:
                self.screen.blit(self.scaled, (0, 0))
        else:
            self.screen.blit(self.canvas, (0, 0))
        pygame.display.flip()

    def to_canvas(self, pos):
        x = (pos[0] - self.offset[0]) / self.scale
        y = (pos[1] - self.offset[1]) / self.scale
        return (int(x), int(y)) if 0 <= x < CANVAS_W and 0 <= y < CANVAS_H else None
```

不用 `pygame.SCALED`：部分 Windows 环境会报 `failed to create renderer`，自绘缩放更可控。

## 10. 入口与主循环（`main.py`）

```python
def main():
    enable_dpi_awareness()
    pygame.mixer.pre_init(22050, -16, 1, 512)
    pygame.init()
    pygame.display.set_caption(APP_NAME)
    try:
        pygame.display.set_icon(pygame.image.load(resource_path("assets", "icon.png")))
    except (pygame.error, FileNotFoundError):
        pass

    profile = load_profile()
    display = Display(profile.settings.fullscreen)
    renderer = Renderer()
    audio = Audio(profile.settings.music, profile.settings.sfx)
    effects = Effects()
    keymap = Keymap()
    clock = pygame.time.Clock()

    screen = "menu"                 # menu / select / game / settings / ranking / over / clear
    dialog = None                   # None / "pause" / "restart"
    session = None
    levels = load_level_index()      # 4 条元信息（id/name/theme/可用性）
    accumulator = 0.0

    running = True
    while running:
        frame_ms = clock.tick(FPS)
        dt = min(frame_ms / 1000.0, 0.05)          # 单帧上限 50 ms，防止切窗口后瞬移

        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False
            elif event.type == pygame.KEYDOWN:
                if event.key == pygame.K_F11:
                    _toggle_fullscreen(display, profile)
                elif event.key == pygame.K_ESCAPE or event.key == pygame.K_p:
                    _on_pause_key(...)
                elif screen == "game" and session and keymap.keydown(event.key):
                    pass                              # 已由 keymap 记录
                else:
                    _on_ui_key(event.key, ...)
            elif event.type == pygame.KEYUP:
                keymap.keyup(event.key)
            elif event.type == pygame.MOUSEBUTTONDOWN and event.button == 1:
                pos = display.to_canvas(event.pos)
                if pos:
                    _on_click(pos, ...)
            elif event.type == pygame.MOUSEMOTION:
                _on_hover(display.to_canvas(event.pos), ...)

        if screen == "game" and session and dialog is None:
            intent = keymap.sample()
            accumulator += dt
            steps = 0
            while accumulator >= PHYSICS_DT and steps < MAX_SUBSTEPS:
                session.step(intent, PHYSICS_DT)
                accumulator -= PHYSICS_DT
                steps += 1
            if steps == MAX_SUBSTEPS:
                accumulator = 0.0                     # 丢弃积压，防止落后越积越多
            _consume_session_events(session, audio, effects, renderer) 
            effects.update(dt)

        _draw_frame(...)
        display.present()
```

事件消费（唯一的声音/特效入口）：

```python
SFX_BY_EVENT = {
    "jump": "jump", "coin": "coin", "stomp": "stomp", "bump": "bump",
    "brick_break": "brick", "powerup": "powerup", "powerdown": "powerdown",
    "fire": "fire", "death": "death", "clear": "clear",
    "checkpoint": "checkpoint", "oneup": "oneup", "gameover": "death",
}

def _consume_session_events(session, audio, effects, renderer):
    snap = session.snapshot()
    for hook in session.effects_hooks:
        effects.on_model_hook(hook, snap)
    session.effects_hooks.clear()
    for ev in session.take_events():
        snd = SFX_BY_EVENT.get(ev.kind)
        if snd:
            audio.play(snd)
        effects.on_event(ev, snap)
```

**关键约束**

- `session.step()` 只在 `screen == "game"` 且 `dialog is None` 时调用：暂停、设置、结算期间时间不推进。
- 切界面时调用 `keymap.clear()`，防止回到游戏后角色「自己往右跑」。
- 退出路径：窗口关闭 / 主菜单「退出」→ 先 `save_profile()` 再 `pygame.quit()`。
- 生命与分数跨关继承：`session.lives`、`session.score` 在进入下一关时传入新 `LevelSession`。
- `load_level_index()` 只扫描 `assets/levels/*.json` 读取 `id/name/theme/cols`，解析失败只把该关标记为不可用，不阻断启动。
- `MAX_SUBSTEPS` 触顶时把 `accumulator` 清零：宁可让游戏慢 1 帧，也不要让角色瞬移穿过地形。
